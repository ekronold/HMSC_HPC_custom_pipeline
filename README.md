# HMSC_HPC_custom_pipeline
Collection of scripts to run Hmsc models on hpc clusters for Oslo Mycology Group, currently set up for the Olivia and Saga clusters at hosted by NRIS

Container with all the software to run HMSC-HPC models following the initial Script_01 can be downloaded from Zenodo:

https://doi.org/10.5281/zenodo.20664829


Example scripts for post-processing in R will follow soon
